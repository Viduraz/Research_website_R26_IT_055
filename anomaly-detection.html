Pose-Based Anomaly Detection

R.M.V.R. Rathnayaka leads temporal pose analysis for supported anomalous and unusual movement patterns.

R.M.V.R. Rathnayaka · Project Leader
Student ID: IT22075208 · Component Owner
Component owner · R.M.V.R. Rathnayaka · IT22075208

Recognize patterns across movement, not a single frame

The anomaly component extracts pose landmarks from video, builds temporal skeletal features and evaluates movement sequences. The goal is to surface events such as falls, aggressive actions, prolonged inactivity and other movement outside expected patterns.

The project design uses movement representations in analysis records to reduce unnecessary exposure to raw footage. Camera snapshots are described as transient diagnostics in the supplied component notes.

Hybrid analysis

Known events and unusual movement

01

LSTM sequence classifier

Evaluates temporal skeletal-joint sequences for supported trained event classes, including falls, aggression and prolonged inactivity.

02

Autoencoder signal

Uses reconstruction error over movement sequences to support checks for patterns outside the trained event classes.

03

Decision logic

The supplied implementation notes describe priority logic across LSTM output, MediaPipe rules and threshold classifiers, with autoencoder analysis supporting unusual-movement checks.
