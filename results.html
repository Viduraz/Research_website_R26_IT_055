Schedule activity results

Claims need their evaluation context

Schedule-monitoring documentation lists activity precision and recall values: Sleep 92% / 95%, Eating 88% / 85%, Drinking 83% / 80%, Talking 78% / 76%, Walking 85% / 90%, Sitting/rest 90% / 88%, and Standing up 76% / 78%.

These are documented project claims. The inspected component notes say no matching benchmark script, evaluation dataset or reproducible metrics output was found. They are therefore presented as reported values, not independently validated results. The active browser classifier is documented as a five-class contract; Talking and Standing up are not in that active class list.

Interpretation

  • Component metrics use different measurement descriptions.
  • Hardware, sample counts and test splits are not consistently supplied.
  • Reported confidence is not the same as accuracy.
  • Field performance requires testing in the intended care setting.
Implementation outcomes

Integrated component capabilities

Identification

Face verification plus skeletal anthropometry and gait analysis, with an unknown-person rejection path.

Tracking

Person tracks, configurable polygon zones, exit detection and caregiver visibility escalation.

Anomaly analysis

Temporal pose features, sequence classification and out-of-pattern movement signals.

Schedule monitoring

Activity observations compared with care routines and recorded for reports and notifications.
